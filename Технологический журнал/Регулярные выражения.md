## 4. Основные команды, полезные при анализе ТЖ в bash

*   **`man`** — описание команды, например `man grep`, `man awk`; то же что и `/?` в командной консоли Windows.
    *   *Другой вариант* — выполнить команду с ключом `--help`, например `grep --help`.
*   **`ls`** — список файлов и папок текущей директории.
*   **`cd locks`** — перейти в поддиректорию `locks`.
*   **`cd ..`** — перейти на уровень выше.
*   **`clear`** — очистить терминал (то же, что и `Ctrl-L`).
*   **`history`** — последние команды, выводятся с номером команды вначале.
    *   **`!123`** — повторно выполнить команду с номером 123.

Конвейеры (pipes):
*   **`Команда1 | Команда2`** — конвейер, передача результата `Команды1` как входные данные для `Команды2`.
*   То же самое, в многострочном режиме:
    ```bash
    Команда1 |\
    Команда2
    ```

Чтение и работа с текстом:
*   **`cat rphost*/*.log 1cv8*/*.log`** — прочитать все файлы с расширением `log` из всех папок, которые начинаются на `rphost`, `1cv8`.
*   **`wc -l`** — посчитать число строк (в входном потоке или файле).
*   **`sort`** — сортировка текста, например `(sort -rnb)` — сортировать текст в обратном порядке (`-r`), пытаться привести текст к числу (`-n`), игнорировать ведущие пробелы и табуляции (`-b`).
*   **`head -n 15`** — вывести 15 первых строк прочитанного текста. Если без параметра `-n`, то выводит по умолчанию 10 строк.
*   **`tail -n 15`** — вывести 15 последних строк прочитанного текста. Если без параметра `-n`, то выводит по умолчанию 10 строк.
*   **`uniq -c`** — вывести только уникальные строки и посчитать их число (ключ `-c`).
*   **`time Команда1 | Команда2`** — вывести время выполнения команды или последовательности команд.
*   **`grep`** — поиск в тексте строк по шаблону — регулярному выражению.
*   **`awk`** (или **`gawk`**) — скриптовый язык, позволяет построчно анализировать и обрабатывать текст.
*   **`sed`** — потоковый редактор текста (Stream EDitor), построчно анализирует текст и осуществляет замену в тексте, вставку или удаление строк. Не понимает символ перевода строки `\n`, так как анализирует текст построчно.

## 5. Примеры использования регулярных выражений для анализа ТЖ. Демонстрация использования grep

Ниже приведены примеры работы с регулярными выражениями на примере утилиты **grep** (`grep -P`, `grep -E`) в оболочке Git bash:

*   `grep` с ключом **`-P`** позволяет использовать синтаксис **perl** регулярных выражений.
*   `grep` с ключом **`-E`** или **`egrep`** позволяет использовать расширенный синтаксис регулярных выражений.

Некоторые конструкции работают только с ключом `-P`, некоторые только с ключом `-E`, для некоторых конструкций оба этих ключа не обязательны.

### 1. Найти все события CALL и SCALL. Вывести первые 30 найденных строк
*   `?` — означает, что предшествующий символ (буква S) присутствует ноль или один раз.

```bash
cat c:/1c_logs/calls/rphost_*/*.log | grep -P ',S?CALL,' | head -n 30
```

### 2. Найти все события CALL, у которых присутствует атрибут Context
*   `.` — означает любой символ.
*   `+` — означает, что предшествующий символ (если точка, то любой символ) повторяется **один** или неограниченное число раз.
*   `*` — означает, что предшествующий символ (если точка, то любой символ) повторяется **ноль** или неограниченное число раз.

Здесь ищутся все строки, в которых есть текст `,CALL`, затем любой набор символов, затем текст `Context=`. Выводятся на экран первые 10 найденных строк (`head` без параметров):

```bash
cat c:/1c_logs/calls/rphost_*/*.log | grep -P ',CALL.+Context=' | head
```
или
```bash
cat c:/1c_logs/calls/rphost_*/*.log | grep -P ',CALL.*Context=' | head
```

### 3. Найти все строки, которые содержат событие TTIMEOUT во всех подкаталогах locks/rphost_*
Найденные слова будут подсвечены на экране (ключ `--color`):

```bash
cat c:/1c_logs/locks/rphost_*/*.log | grep 'TTIMEOUT' --color
```

### 4. Найти все строки, которые содержат либо TLOCK, либо TDEADLOCK
Вывести последние 10 найденных строк (`tail` без параметров).
*   `(DEAD)?` — означает, что последовательность символов в скобках необязательна.

```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'T(DEAD)?LOCK' --color
```

### 5. То же самое, но с помощью конструкции `.{,4}` или `\w{,4}`
*   `.` — означает любой символ.
*   `\w` — означает любой алфавитный символ.
*   `{,4}` — от нуля до четырех раз повторяется предшествующий символ.

В первом примере предшествующий символ — точка, то есть любой символ. Во втором примере предшествующий символ — `\w`, то есть любой алфавитный символ. Найденные слова будут подсвечены на экране:

```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -E 'T.{,4}LOCK' --color
```
или
```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'T\w{,4}LOCK' --color
```

### 6. То же самое, но с помощью конструкции `(DEAD|)`
*   `(DEAD|)` — означает, что в слове TLOCK присутствует фрагмент DEAD, либо ничего. Найденные слова будут подсвечены на экране:

```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'T(DEAD|)LOCK' --color
```

### 7. Найти все события TDEADLOCK и TTIMEOUT
Найденные слова будут подсвечены на экране:

```bash
cat c:/1c_logs/*/rphost_*/*.log | grep -P 'T(DEADLOCK|TIMEOUT)' --color
```

### 8. Найти все события TLOCK, у которых не пустое поле WaitConnections
Иначе говоря, найти все ожидания на управляемых блокировках 1С.
*   `.` — означает любой символ.
*   `*` — означает, что предшествующий символ (то есть точка - любой символ) повторяется ноль или неограниченное число раз.
*   `[1-9]` — означает любой символ из диапазона между 1 и 9.
*   `\d` — означает любой числовой символ.

Найденные слова будут подсвечены на экране:

```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'TLOCK.+WaitConnections=[1-9]' --color
```
или
```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'TLOCK.+WaitConnections=\d' --color
```

### 9. Найти все разделяемые (Shared) управляемые блокировки
*   `.` — означает любой символ.
*   `+` — означает, что предшествующий символ (то есть точка - любой символ) повторяется один или неограниченное число раз.
*   `\b` — означает границу слова, в данном случае `\bShared\b` означает, что мы ищем слово Shared целиком, слева и справа от Shared могут быть только пробел, табуляция, перевод строки.
*   `\s` — любой пробельный символ (пробел, табуляция, перевод строки).

Найденные слова будут подсвечены на экране:

```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'TLOCK.+\bShared\b' --color
```
или
```bash
cat c:/1c_logs/deadlocks/rphost_*/*.log | grep -P 'TLOCK.+\sShared\s' --color
```

### 10. Вывести все исключительные ситуации, которые произошли в 21:40
*   `^` — означает начало строки, то есть `^40` означает, что 40 должно быть в начале строки.
*   `.+` — любая последовательность символов, но не менее одного символа.

```bash
cat c:/1c_logs/err/rphost_*/*21.log | grep -P '^40:.+EXCP' --color
```

**7. Демонстрация использования awk**

**awk** - утилита, скриптовый язык для анализа и редактирования текста
Считается предшественником perl

**awk** используется при анализе логов ТЖ для:

*   Разбиения строки на подстроки
*   Агрегирования (сумма, среднее, минимум, максимум) значений какой либо подстроки
    Если строку или начало строки можно привести к числу, **awk** умеет это делать.
*   Преобразования многострочного текста к однострочному
    Например текста запроса к одной строке, многострочного контекста кода 1С к одной строке

**gawk (GNU awk)** - обладает дополнительными по отношению к **awk** возможностями, в том числе позволяет использовать расширенный синтаксис регулярных выражений

Пример использования **awk (gawk)**:

```bash
gawk -F'РазделительПодстрок' -v RS='РегВыражениеПереводСтроки' '/УсловиеПоиска/ {скрипт}'
```

$0 - вся строка целиком
$1, $2, ... - подстроки 1, 2 и так далее
Строка разбивается на подстроки с использованием разделителя.
Разделитель по умолчанию - пробел или табуляция.
Специальный разделитель может быть указан с помощью ключа -F
Разделителем может быть символ или любая подстрока, в том числе с использованием регулярных выражений

print $1 - выводит на экран подстроку 1
print $0 - выводит на экран строку целиком

**4. Найти 10 входящих клиент-серверных вызовов (CALL), которые имеют самую большую длительность суммарно**

С помощью **grep** находим все **CALL** с не пустым контекстом
Удаляем не нужные куски текста с помощью **sed**

Получаем текст вида:

```text

Теперь с помощью **gawk** обходим все полученные строки, для каждой строки помещаем в ассоциативный массив **Dur** контекст кода 1С (подстрока $2) и суммируем длительность (подстрока $1).
Аналогом ассоциативного массива в 1С является объект "Соответствие".

gawk -F',' '{Dur[$2]+=$1} END {for (i in Dur) print Dur[i] ": " i}' |\
sort -rnb |\
head -n 5
```
